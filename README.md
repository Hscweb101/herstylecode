# HerStyleCode

Direct-to-customer fashion jewellery e-commerce website with a full admin panel, built with React + Supabase + Razorpay.

**Start here:** [`documentation/README.md`](documentation/README.md) — full project overview, tech stack, and setup.

Also in `documentation/`:

- `PROJECT_STATUS.md` — checklist of what's built vs. what needs your own accounts (Razorpay, email, etc.)
- `SCHEMA.md` — database design explained
- `SUPABASE_TRANSFER.md` — how to move the project to your own Supabase account
- `RAZORPAY_SETUP.md` — activating real payments
- `ADMIN_GUIDE.md` — using the admin panel
- `DEPLOYMENT.md` — deploying the site
- `ENV_VARS.md` — environment variable reference

## Quick Start

```bash
npm install
npm run dev
```
